Preguntas frecuentes

Todo lo que quieres saber

¿Necesito instalar algo para usar Brakket?
No, es una aplicación web responsiva, accesible desde cualquier navegador moderno.
¿Cómo se conecta mi canal de Twitch?
Se vincula desde el panel administrativo mediante autorización oficial de la API de Twitch.
¿Qué formatos de torneo soporta?
Eliminación simple, eliminación doble, round robin y formato suizo, según el perfil competitivo del juego.
¿Cómo funcionan las disputas?
Un participante reporta el resultado; si hay desacuerdo, se puede impugnar con evidencia, y un árbitro resuelve con trazabilidad completa.
¿Los patrocinadores pueden ver mis datos privados?
No. Solo acceden a métricas de audiencia y participación de las competencias donde están asociados.
